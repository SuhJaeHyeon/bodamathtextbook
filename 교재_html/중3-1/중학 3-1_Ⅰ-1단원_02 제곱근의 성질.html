개념 01
제곱근의 성질
$a > 0$일 때
(1) $(\sqrt{a})^2 = a$,  $(-\sqrt{a})^2 = a$  — 제곱근을 제곱하면 근호가 사라진다.
예
$(\sqrt{3})^2 = 3$,  $(-\sqrt{3})^2 = 3$
(2) $\sqrt{a^2} = a$,  $\sqrt{(-a)^2} = a$  — 양수를 제곱한 뒤 근호를 씌우면 다시 원래 수가 된다.
예
$\sqrt{3^2} = 3$,  $\sqrt{(-3)^2} = 3$
예제 01
다음 중 그 값이 나머지 넷과 다른 하나는?
① $\sqrt{5^2}$ ② $(\sqrt{5})^2$ ③ $(-\sqrt{5})^2$ ④ $\sqrt{(-5)^2}$ ⑤ $-\sqrt{5^2}$
참고
$(\sqrt{a})^2$과 $\sqrt{a^2}$의 차이

$(\sqrt{a})^2$ : $\sqrt{a}$를 두 번 곱한 것
$\sqrt{a^2}$ : $a^2$의 양의 제곱근
풀이 TIP
  • $-\sqrt{(-2)^2} = -\sqrt{4} = -2$로, 나머지가 모두 양수임에 주목한다.

개념 02
$\sqrt{a^2}$의 성질
모든 수 $a$에 대하여  $\sqrt{a^2} = |a|$  — $a$의 부호에 상관없이 결과는 항상 $0$ 이상이다.
$a \ge 0$이면 $\sqrt{a^2} = a$  /  $a < 0$이면 $\sqrt{a^2} = -a$
예
$\sqrt{5^2} = 5$,  $\sqrt{(-5)^2} = 5$  ($a$가 음수여도 결과는 양수)
예제 02
$a < 0$일 때, 다음 수 중 그 값이 양수인 것의 개수를 구하시오.
$(\sqrt{-a})^2,\enspace \sqrt{(-4a)^2},\enspace -\sqrt{a^2},\enspace -\sqrt{(2a)^2}$
참고
$a < 0$이면
$\sqrt{a^2} = |a| = -a > 0$

즉, $a$의 부호와 $\sqrt{a^2}$의 부호는 반대가 된다.
풀이 TIP
  • $a < 0$이면 $\sqrt{a^2} = -a > 0$임을 이용하여 각 항의 부호를 판단한다.

개념 03
제곱근의 대소 관계
$a > 0$, $b > 0$일 때
(1) $a < b$이면 $\sqrt{a} < \sqrt{b}$  — 근호 안의 수가 클수록 제곱근도 크다.
(2) $\sqrt{a} < \sqrt{b}$이면 $a < b$  — 제곱근이 클수록 근호 안의 수도 크다.
(3) $\sqrt{a} < \sqrt{b}$이면 $-\sqrt{a} > -\sqrt{b}$  — 부호가 바뀌면 대소 방향도 바뀐다.
예
$2 < 3$이므로 $\sqrt{2} < \sqrt{3}$,  $-\sqrt{2} > -\sqrt{3}$
예제 07
다음 중 두 수의 대소관계가 옳은 것은? (제곱근의 대소 관계)
① $5 > \sqrt{27}$ ② $0.3 > \sqrt{0.3}$ ③ $-\sqrt{(-4)^2} > -\sqrt{17}$ ④ $\sqrt{\dfrac{2}{5}} > \sqrt{\dfrac{2}{3}}$ ⑤ $-\sqrt{26} > -5$
참고
근호가 없는 수와 비교할 때

방법1 근호가 없는 수를 $\sqrt{\phantom{0}}$ 형태로 바꿔 비교한다.
방법2 두 수를 각각 제곱하여 비교한다.

예) $\sqrt{7}$과 $3$: $3=\sqrt{9}$이고 $7<9$이므로 $\sqrt{7}<3$
풀이 TIP
  • 근호가 없는 수는 $\sqrt{\phantom{0}}$ 형태로 바꾸거나 제곱하여 비교한다. 음수는 부등호 방향이 반대가 됨에 주의한다.

한눈에 보는 개념 정리
01 제곱근의 성질
$a > 0$일 때, $(\sqrt{a})^2 = a$, $(-\sqrt{a})^2 = a$, $\sqrt{a^2} = a$, $\sqrt{(-a)^2} = a$
→ 제곱근과 제곱은 서로 반대 연산이므로, 한 쪽을 적용하면 근호가 없어진다.
02 $\sqrt{a^2}$의 성질
$\sqrt{a^2} = |a|$  — $a$의 부호와 관계없이 결과는 항상 $0$ 이상이다.
$a \ge 0$이면 $\sqrt{a^2} = a$,   $a < 0$이면 $\sqrt{a^2} = -a$ (부호를 반대로 바꿔 양수로 만든다)
03 제곱근의 대소 관계
$a > 0$, $b > 0$일 때:  $a < b \Leftrightarrow \sqrt{a} < \sqrt{b}$  — 근호 안의 수가 클수록 제곱근도 크다.
음수 비교: $\sqrt{a} < \sqrt{b}$이면 $-\sqrt{a} > -\sqrt{b}$ (부호가 바뀌면 대소도 바뀐다)
근호가 없는 수와 비교할 때는 둘 다 근호 형태로 바꾸거나, 둘 다 제곱하여 비교한다.
